# 🏠 Trouve ton artisan - Région Auvergne-Rhône-Alpes

Plateforme web permettant aux particuliers de trouver et contacter facilement des artisans qualifiés de la région Auvergne-Rhône-Alpes.

## 🎯 Projet

Application développée dans le cadre de la formation Développeur Web. Ce projet mobilise React.js, Express, MySQL et démontre la mise en place d'une API REST complète avec interface utilisateur responsive.

## 🛠 Technologies utilisées

- **Frontend** : React.js, Bootstrap, Sass
- **Backend** : Node.js, Express, Sequelize
- **Base de données** : MySQL
- **Sécurité** : Helmet, CORS, Rate Limiting, Express Validator

## 📦 Prérequis

- Node.js (v16+)
- MySQL (v8+)
- npm

## 🚀 Installation

### Backend
```bash
cd backend
npm install
# Créer un fichier .env (voir .env.example)
# Créer la BDD avec les scripts SQL dans database/
npm start
```

### Frontend
```bash
cd frontend
npm install
# Créer un fichier .env (voir instructions)
npm start
```

Le site s'ouvre sur http://localhost:3000

## ✨ Fonctionnalités

- Recherche d'artisans par nom
- Filtrage par catégorie (Bâtiment, Services, Fabrication, Alimentation)
- Fiches détaillées des artisans
- Formulaire de contact
- Design responsive (mobile-first)
- Accessibilité WCAG 2.1
